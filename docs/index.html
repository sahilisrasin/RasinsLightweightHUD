Features

What RLHUD includes

Each feature is listed with its current development status. Only features verified as working are marked Available.

  • Armor Durability HUD

    In Development

    Shows the durability of equipped armor pieces on screen.

  • Keystrokes

    In Development

    Displays movement and action key presses.

  • CPS Counter

    In Development

    Shows clicks per second for combat practice and tracking.

  • FPS Display

    In Development

    Shows the current frame rate.

  • Ping Display

    In Development

    Shows the current network latency to the server.

  • HUD Customization

    Planned

    Options to reposition and adjust HUD elements.

  • Combat Information

    Planned

    Additional combat-related readouts.

Installation

How to install

  1. Install Fabric for Minecraft 1.21.11

    Install the Fabric Loader for Minecraft 1.21.11 using the official Fabric installer.

  2. Download the RLHUD player JAR

    Use the Download RLHUD 1.0.0 button above. This is rlhud-1.0.0.jar.

  3. Place the JAR in your mods folder

    Copy the file into the mods folder inside your Minecraft directory.

  4. Launch with the Fabric profile

    Start Minecraft using the Fabric profile you created in the launcher.

Dependencies: Check the mod's metadata in the repository (opens in a new tab) for any required Fabric API dependency before launching.

Development

About the project

Rasin's Lightweight HUD is a PvP HUD for Minecraft Java Edition, built with Java and the Fabric modding framework. The project is open source and available under the MIT license.

Current development status: version 1.0.0 is published. Features marked In Development on this page are not yet complete.
