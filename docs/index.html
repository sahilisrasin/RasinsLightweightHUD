Features

What RLHUD does today

RLHUD is developed in the open, so statuses stay honest: Available means it ships in the published build, Planned means it is on the roadmap but not implemented yet.

  • Armor Durability HUD

    Available

    Durability for Head, Chest, Legs and Feet, color-coded by condition: green above 50%, orange up to 50%, red at or below the 20% low-durability threshold. Empty slots show --; items that can't take damage show OK.

  • FPS Display

    Available

    A live frames-per-second readout built into the RLHUD panel header, rendered alongside the armor lines.

  • Keystrokes

    Planned

    An on-screen display of your keyboard and mouse input for movement and combat. Not implemented in 1.0.0.

  • CPS Counter

    Planned

    A clicks-per-second counter for both mouse buttons. Not implemented in 1.0.0.

  • Ping Display

    Planned

    A network latency readout next to the rest of the HUD. Not implemented in 1.0.0.

  • HUD Customization

    Planned

    Moveable, toggleable modules with saved settings and in-game configuration. In 1.0.0 the panel has a fixed position.

  • Combat Information

    Planned

    Additional combat-focused modules for PvP scenarios. Not implemented in 1.0.0.

Statuses reflect the 1.0.0 (ArmorHUD) build as published on GitHub Releases. Track progress on the repository.

Installation

Up and running in four steps

  1. Install Fabric for Minecraft 1.21.11

    Use the official Fabric installer, select Minecraft 1.21.11, and install the Fabric Loader profile.

  2. Add Fabric API

    RLHUD requires Fabric API. Download a build for 1.21.11 and put it in your mods folder too.

  3. Drop in the RLHUD player JAR

    Download the RLHUD player JAR and place it inside your Minecraft mods folder (.minecraft/mods on Windows).

  4. Launch the game

    Start Minecraft with the Fabric profile. The RLHUD panel appears in the top-left corner; hiding the HUD (F1) hides it as usual.

Development

Built in the open

RLHUD is a work-in-progress, all-in-one PvP HUD suite for Minecraft Java Edition — the goal is one small, resource-conscious mod instead of a pile of separate PvP mods. It is written in Java on the Fabric toolchain and built with the Gradle wrapper included in the repository.

Development happens in the open on GitHub. The current state is early development: the ArmorHUD prerelease (1.0.0) is the first published build, and modules beyond the armor HUD and FPS readout are not implemented yet — see the feature statuses above.
